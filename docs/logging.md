# Документація системи логування — TechVolt Landing

## Огляд

Система логування TechVolt реалізована на стороні клієнта (браузер) засобами Vanilla JavaScript без зовнішніх залежностей. Складається з двох модулів: `js/logger.js` та `js/error-handler.js`.

---

## Рівні логування

Визначено п'ять рівнів у порядку зростання важливості: DEBUG (0), INFO (1), WARN (2), ERROR (3), CRITICAL (4). Рівні нижче встановленого мінімуму не виводяться.

---

## Зміна рівня без перекомпіляції

Мінімальний рівень логування зчитується з localStorage при кожному виклику — зміна набуває чинності миттєво без перезавантаження сторінки.

```javascript
// У консолі браузера (F12):
Logger.setLevel('DEBUG');   // показати всі логи
Logger.setLevel('WARN');    // показати лише попередження та помилки
Logger.setLevel('ERROR');   // показати лише помилки
```

Також можна встановити через window перед завантаженням скриптів:
```javascript
window.TECHVOLT_LOG_LEVEL = 'DEBUG';
```

---

## Формат логу

Кожен запис містить: `timestamp` (ISO 8601), `level`, `module`, `message`, `sessionId`, `url`, `userAgent` та довільний контекст.

```json
{
  "timestamp": "2025-01-01T12:00:00.000Z",
  "level": "ERROR",
  "module": "Cart",
  "message": "Не вдалося зберегти кошик",
  "sessionId": "sess_ABC12345",
  "errorId": "ERR-LF3K2A-X9P1",
  "url": "https://Gazman4iK1.github.io/techvolt-landing-v2/",
  "userAgent": "Mozilla/5.0 ..."
}
```

---

## Ротація логів

Логи рівнів ERROR та CRITICAL зберігаються в localStorage під ключем `techvolt_logs`. При досягненні 100 записів автоматично видаляються 20 найстаріших — реалізовано в методі `persistLog()` файлу `js/logger.js`.

```javascript
Logger.getLogs();    // переглянути всі збережені логи
Logger.clearLogs();  // очистити журнал
```

---

## Унікальні ідентифікатори помилок

Кожна помилка отримує унікальний ID формату `ERR-TIMESTAMP-RANDOM` (наприклад `ERR-LF3K2A-X9P1`). ID відображається в toast-повідомленні для користувача та логується для розробника, що дозволяє однозначно ідентифікувати конкретний інцидент.

---

## Перехоплення помилок

Система автоматично перехоплює всі необроблені помилки через `window.addEventListener('error', ...)` та необроблені Promise rejection через `window.addEventListener('unhandledrejection', ...)`.

---

## Локалізація повідомлень

Повідомлення для користувачів локалізовані українською та англійською мовами. Мова визначається автоматично за атрибутом `lang` тега `<html>`. Технічні деталі помилок приховані від користувача — відображаються лише зрозумілі інструкції та унікальний ID для звіту.

---

## Повідомлення про проблему

Кнопка «Повідомити про проблему» у toast-повідомленні та на сторінці error.html відкриває поштовий клієнт з попередньо заповненим листом: ID помилки, URL сторінки, браузер та поле для кроків відтворення.

---

## Підключення до сторінок

```html
<!-- Підключати в такому порядку — logger.js перший -->
<script src="js/logger.js"></script>
<script src="js/error-handler.js"></script>
<script src="script.js"></script>
```

---

## Приклади використання

```javascript
// Інформаційне логування
Logger.info('Cart', 'Товар додано до кошика', { productId: 5, qty: 1 });

// Попередження
Logger.warn('Navigation', 'Елемент не знайдено', { selector: '#missing' });

// Обробка помилки з контекстом
try {
  riskyOperation();
} catch (e) {
  ErrorHandler.handle(e, 'Cart', { productId: 5, action: 'add' });
}
```
